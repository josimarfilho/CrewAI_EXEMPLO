# README - Exemplo de CrewAI

## 📌 Visão Geral
Este repositório contém um exemplo de implementação utilizando o framework CrewAI, demonstrando como criar e gerenciar agentes autônomos para executar tarefas específicas.

## 🚀 Tecnologias Utilizadas
- [CrewAI](https://www.crewai.com/) - Framework para construção de agentes autônomos
- Python 3.x
- [Outras dependências listadas no requirements.txt]

## ⚙️ Configuração do Ambiente

1. Clone o repositório:
```bash
git clone https://github.com/josimarfilho/CrewAI_EXEMPLO.git
cd CrewAI_EXEMPLO
```

2. Crie e ative um ambiente virtual (recomendado):
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. Instale as dependências:
```bash
pip install -r requirements.txt
```

## 🏃 Como Executar

Execute o exemplo principal com:
```bash
python main.py
```
